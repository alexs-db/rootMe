I imagine that beforehand, you did some research in the ch20.zip directory. Very quickly you understood that it contained a profile: o0s0xxhl.default.
## Instructions

1. **Remember its path.**

2. **Download the famous Python tool** from the following GitHub repository: [https://github.com/Unode/firefox_decrypt](https://github.com/Unode/firefox_decrypt).

3. **After extracting**, navigate to the directory containing the `firefox_decrypt.py` Python file.

4. **To discover the password**, run the script with the command:
    ```sh
    python firefox_decrypt.py PATH_TO_FIREFOX_PROFILE
    ```
