This challenge is based on Caesar encryption.

You have a lot of pages on Internet wich talk about that.

The main principle is the fact that all the letter are encrypted by  a modulo 26 shift based on the position of the letter in the alphabet.

For example : 

If we want to encode X with a shift of 3.

X is the 24th letter.

24 + 3 = 27 or 27 is bigger than 26 so we have to take the modulo.

27 mod 26 = 27 - 26 * 1 = 1.

The letter in the first position is A.

So with a shift of 3, X will become A.
